## 1. 总体思路与顺序调整

原始计划：语言 → ROS → 算法 → 仿真，数学带着看。

**总体合理**（尤其"数学带着看"对工程岗完全正确），仅做两处微调：

| 调整点 | 原计划 | 调整后 | 理由 |
|---|---|---|---|
| 仿真位置 | 放最后 | **提前穿插** | 仿真是"练习场"而非"大考"：学语言时写控制器脚本、学 ROS 时接仿真、学 RL 时仿真是前置必需品 |
| ROS 版本 | 未指定 | **直接 ROS2** | ROS1 已于 2025 年 EOL 停止维护，公司新项目基本全是 ROS2 |

调整后主线：**语言 → 仿真入门（提前）→ ROS2 → PyTorch → RL → 模仿学习/VLA**，数学与机器人学按需穿插。

## 2. 阶段 0：环境准备

**预计时长**：1~2 周

### 学习内容

- [ ] 安装 Ubuntu 22.04 或 24.04（ROS2 原生环境；双系统或 WSL2 均可，本机已是 WSL2 环境，参考[学习笔记](mujoco-learning-notes.md)）
- [ ] 熟悉命令行操作、shell 脚本基础、apt / conda / uv 包管理
- [ ] Git：分支、回滚、PR 流程
- [ ] VSCode + Remote 远程开发
- [ ] CMake 入门（能看懂、能写简单的 CMakeLists.txt）

### 检验标准

- [ ] 能在纯命令行下完成"拉代码 → 编译 → 运行 → 提交"全流程

## 3. 阶段 1：Python + C++

**预计时长**：2~3 个月（可并行）

### Python（快速过）

- [ ] 语法 → 面向对象 → 异常 / 装饰器
- [ ] **NumPy 重点精通**（机器人开发天天用矩阵运算）
- [ ] Matplotlib 基础可视化

**资源**：Python 官方教程；《Fluent Python》（进阶，选读）

### C++（重点投入，工程岗硬门槛）

- [ ] 现代 C++（14/17）：智能指针、RAII、STL 容器与算法、类设计、移动语义
- [ ] 用 CMake 组织 C++ 工程
- [ ] gdb 调试基本操作

**资源**：[learncpp.com](https://www.learncpp.com/)（免费、系统）；《Effective Modern C++》（进阶）；《C++ Primer》（当字典查）

> ⚠️ **不追求"学完"C++**：能读、能写、能调试就进入下一阶段，深度留给后续项目补。

### 检验项目

- [ ] 用 C++ 写一个小型运动学库：3D 坐标变换、旋转矩阵 / 四元数转换
  - 配 Python 绑定（pybind11），用 NumPy 对拍验证
  - 一石三鸟：语言 + 数学 + 工程结构

### 穿插数学

- 线性代数直观部分：3Blue1Brown《线性代数的本质》

## 4. 阶段 2：MuJoCo 仿真入门

**预计时长**：1 个月（可与阶段 1 后半并行）

### 学习内容

- [ ] 官方 Python 包 `mujoco`（3.x）；**旧包 `mujoco-py` 已废弃，不要碰**
- [ ] 读懂 / 修改 MJCF 模型 XML
- [ ] 加载模型跑仿真、渲染可视化（viewer / 离屏渲染）
- [ ] 了解 `dm_control`（DeepMind 上层封装）

**资源**：MuJoCo 官方文档；本机环境已验证可用，直接参考 [mujoco-learning-notes.md](mujoco-learning-notes.md) 与 [mujoco-guide.md](mujoco-guide.md)

### 检验项目

- [ ] 加载一个官方机械臂模型（如从 [mujoco_menagerie](https://github.com/google-deepmind/mujoco_menagerie) 选取），写 Python 脚本控制其做关节空间运动

### 穿插数学

- 旋转矩阵、四元数（此时结合仿真学效率最高）

## 5. 阶段 3：ROS2 + 工程实践

**预计时长**：2~3 个月

### 学习内容

- [ ] **ROS2（Humble 或 Jazzy）**：节点、话题、服务、action、参数、launch 文件
- [ ] URDF 机器人描述、TF2 坐标变换、rviz2 可视化
- [ ] 选一个方向深入：Nav2（移动机器人导航）或 MoveIt2（机械臂规划）
- [ ] 工程能力：Docker 打包、gtest / pytest 单元测试、GitHub Actions CI

**资源**：ROS2 官方 tutorials（英文但质量最高）；鱼香 ROS（中文社区，入门友好）；古月居

### 检验项目

- [ ] **把 MuJoCo 仿真接入 ROS2**：做一个仿真差速小车或机械臂
  - 键盘遥控 + 里程计发布 + rviz2 可视化 + rosbag 录包回放
  - 这是求职时最经典的工程项目形态

## 6. 阶段 4：PyTorch + 深度学习基础

**预计时长**：1~2 个月

### 学习内容

- [ ] Tensor、autograd、nn.Module、DataLoader、完整训练循环
- [ ] 跑一遍图像分类（ResNet 级别），理解：数据集划分、训练、验证、过拟合、调参

**资源**：《动手学深度学习》（[d2l.ai](https://zh.d2l.ai/)，李沐，中文免费）——只看前半本基础部分即可

### 检验标准

- [ ] 能从零手写训练循环，不依赖抄来的模板

---

## 7. 阶段 5：RL + 仿真实操

**预计时长**：2~3 个月

### 学习内容

- [ ] RL 基础概念：MDP、Q-learning、Policy Gradient
- [ ] **PPO、SAC（重点掌握）**
- [ ] 工具链：Gymnasium + MuJoCo 环境（阶段 2 积累直接复用）
- [ ] 进阶：Isaac Lab（GPU 大规模并行训练，业界主流；需要 CUDA 环境）

**资源**：OpenAI Spinning Up（经典入门）；《动手学强化学习》（赵世钰，中文免费）；Sutton & Barto 教材（当字典查）

### 穿插数学

- 梯度与反向传播、采样、高斯分布

### 检验项目

- [ ] 在 MuJoCo 里完整训练一个任务（机械臂抓取 / 小车导航避障）
  - 走通"环境搭建 → 训练 → TensorBoard 分析 → 调参 → 评估"全流程
  - 理解 sim-to-real 的域随机化思路

---

## 8. 阶段 6：模仿学习 + VLA

**预计时长**：2~3 个月（求职加分核心）

### 学习内容

- [ ] 模仿学习：行为克隆（BC）→ **Diffusion Policy / ACT**（读论文 + 跑开源代码）
- [ ] VLA：了解 RT-2、OpenVLA、π0 的架构差异；跑通 OpenVLA 推理
- [ ] 工具：**LeRobot**（Hugging Face 出品，工程友好，业界在用）

### 检验项目

- [ ] 用 LeRobot 训练 / 微调一个操作策略（哪怕是仿真数据）
  - 完整走一遍"数据采集 → 训练 → 部署到仿真"

---

## 9. 贯穿始终的任务

- **机器人学**：《Modern Robotics》课程（B 站有中文版）挑运动学 / 控制章节看，不做题
- **作品集**：每个阶段的检验项目都传 GitHub，认真写 README（架构图、运行方式、演示 GIF）
  - 工程岗简历上 **2 个完整项目 > 10 门课程证书**
- **习惯**：读代码多于读书；遇到报错自己排查的能力就是工程能力本身

---

## 10. 时间估算

| 学习模式 | 主干完成时间 |
|---|---|
| 全职学习 | 约 6~8 个月 |
| 业余时间（每天 2~3 小时） | 约 12~14 个月 |

**优先级说明**：

- 阶段 1~3（语言 + 仿真 + ROS2）是工程岗简历的**基本盘**
- 阶段 5~6（RL + 模仿学习 / VLA）是将你与普通 ROS 工程师区分开的**核心竞争力**

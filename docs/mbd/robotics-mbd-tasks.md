## 5. 人天汇总与并行度建议

| 系列 | 合计 | 说明 |
|---|---|---|
| D 系列 | **27 人天** | ≈ 1.5 人 × 3 周，与 demo-plan 排期一致 |
| DL 系列 | **4 人天** | 阶段 1；硬件到货后 2–3 天完成 |
| C 系列 | 7.5 人天 | 可由第 2 人与 D 系列并行推进 |
| J 系列 | ~32 人周 | M1 正式版，仅 J1 提前 |

并行度建议（2 人配置）：

```
人员A:  D1.1→D1.2→D1.3→D1.6→D2.x→D3.x     (主链：策略→真机→演示)
人员B:  D1.4→D1.5→D1.7→D1.8→C1→C2→C3→C4   (副链：RT骨架→契约)
```

关键串行依赖：`D1.2→D1.3→D1.6`（策略链）与
`D2.2→DL1→DL2→DL3→DL4→DL5→D2.3→D2.4→D2.5`（阶段 1 门控 + 真机链）；
其余均可交叉并行。

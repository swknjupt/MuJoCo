## 2. 里程碑定义与验收标准

| 里程碑 | 时间点 | 内容 | 验收标准（量化） |
|---|---|---|---|
| **M0** 接口冻结 | 2026-11 末 | 三份接口契约文档签署 | FPGA/RTOS/软件三方签字；信号字典 v0 定稿 |
| **M1** 单关节台架演示 | 2027-03 末 | 四足关节模组在台架上跑通 RL 策略 + 回退 | ① 1kHz 循环抖动 < 50µs（PREEMPT_RT 档）② overrun 率 < 1e-6 ③ 推理超时→回退接管 < 5ms ④ 连续 30min 无故障 ⑤ 延迟注入下回退触发 ≥ 3 次且可控停机 |
| **M2** 模型编译管线 | 2027-05 末 | MJCF → RT 模型自动化 | ① 新机型导入 < 1 人日 ② 误差证书 v1：关节轨迹偏差 95% 分位 < 10%（相对高保真模型）③ 编译产物通过可调度性检查 |
| **M3** 工具链闭环 | 2027-07 末 | 场景 DSL + 故障注入 + 覆盖度量 | ① 一份场景定义同时产出训练侧配置与台架侧注入序列 ② ≥ 200 退化场景/天自动执行 ③ 覆盖报告含 OOD 角落识别 |
| **M4** 感知回注档 | 2027-09 末 | log-and-replay 感知退化测试 | ① 真机采集数据回注台架 ② 传感器退化场景（丢帧/漂移/延迟）复现率 100% |
| **M5** 认证工具链 | 2027-11 末 | ISO 10218 / 13482 条款映射 | 测试报告 → 法规条款的完整追溯链；governor 组件通过第三方静态/动态验证 |

> 注：M1 的桌上缩小版 Demo 分两阶段：阶段 1 为自由摆仿真/真机对比、少量参数辨识、
> 模型驱动 governor 制动与对比报告（D-Lite，约 2–3 天，硬件到货后先行）；
> 阶段 2 为「起摆–平衡–兜底」完整五幕
> （约 3 周）。两阶段均可在正式排期外独立执行，详见
> [`robotics-mbd-demo-plan.md`](./robotics-mbd-demo-plan.md)；

## 5. 关键路径分析

```
WP0 接口冻结 ──→ WP3 Plant 仿真器 ──┐
        │                            ├──→ WP13 集成 ──→ M1
        └──→ WP1 推理壳 ────────────┤
        └──→ WP2 Governor ──────────┘
WP12 台架机电（采购货期 4 周，与软件并行）──↗
```

- **M1 关键路径：WP0 → WP3 → WP13**（累计约 21 周）。WP3 是最长单项（10 人周），
  且弱依赖 WP5——**M1 允许用手调简化模型绕过 WP5**，这是排期上最重要的解耦决策。
- WP12 采购货期是隐性关键路径：**必须在 T0 立即启动机械设计**，否则集成月空转。
- M2/M3 不在 M1 关键路径上（WP5/WP6 与 WP8–11 可与 M1 后半程并行），
  由模型工程师与工具链工程师独立推进。
- 每月预留 20% 缓冲；集成月（27/03）不排新特性开发，只排 bug 修复与基准测试。

## 7. 外部依赖（FPGA / RTOS 团队）

本排期**不管理**两团队内部计划，但以下交付时间是软件侧的硬前置，需写入三方协议：

| 交付物 | 需要时间 | 阻塞的工作包 | 降级方案 |
|---|---|---|---|
| RTOS：1kHz 主循环 API + overrun 回调（仿真版，可跑在开发机） | 26/12 中 | WP1/2/3 开发 | 软件侧先用 PREEMPT_RT Linux 自搭临时循环 |
| FPGA：确定性 I/O 读写 API + 时间戳 | 27/02 末 | WP13 集成 | 用 IgH EtherCAT + 商品从站临时替代 |
| FPGA：EtherCAT DC 同步 tick | 27/02 末 | WP13 集成 | 同上（牺牲部分同步精度，M1 验收项 ①②放宽） |
| RTOS：GPU/NPU 推理资源配额确认 | 27/01 末 | WP1 定版 | 推理放 host 侧 + 共享内存桥（延迟 +1–2ms） |

## 8. 风险登记表

| # | 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|---|
| R1 | HIL 接口不稳定（真电机×虚拟身体闭环发散） | 高 | M1 延期 | 低速/柔耦合切入；带宽限制器；WP14 的 PHIL spike 提前到 27/01 启动 |
| R2 | FPGA/RTOS 接口延期 | 中 | M1 延期 | 第 7 节降级方案；接口仿真版先行 |
| R3 | NN 推理抖动超预算（timeboxed 内完不成） | 中 | WP1 返工 | 量化/蒸馏预案；最坏情况用上一有效输出 + 回退 |
| R4 | 台架采购货期延误 | 中 | WP13 空转 | T0 立即下单；备选供应商 |
| R5 | 误差证书 v1 达不到 10% 偏差指标 | 中 | M2 放水 | 指标可按工作空间分区域放宽；诚实标注适用范围 |
| R6 | 试点客户需求与产品假设偏离 | 高 | 方向调整 | P4 出口条件强制要求外部试点；每季度客户访谈 |
| R7 | 认证机构对 governor 路径不认可 | 中 | M5 延期 | 提前（27/06 起）与认证机构预沟通，不等 P6 |

## 9. 进度健康度指标

每月例会检查，任一红灯即触发排期复核：

| 指标 | 绿 | 黄 | 红 |
|---|---|---|---|
| 关键路径偏差（WP0/3/13） | < 1 周 | 1–2 周 | > 2 周 |
| 接口变更次数（冻结后） | 0 | 1–2 | ≥ 3 |
| overrun 率（集成期实测） | < 1e-7 | 1e-7–1e-6 | > 1e-6 |
| 降级方案启用数 | 0 | 1 | ≥ 2 |
| 研究线 spike 产出回灌率 | ≥ 50% | 20–50% | < 20% |
